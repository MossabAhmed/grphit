# مصنع الجرافيت — نظام إدارة مبسط لمصنع متوسط

واجهة عربية لإدارة المخزون والمشتريات والمبيعات والمصروفات والرواتب والتقارير باستخدام HTML وCSS وJavaScript فقط.

## ما الذي تم إصلاحه؟

- تخزين البيانات في **IndexedDB** بدل `localStorage`، وهي قاعدة بيانات مجانية مدمجة في المتصفح ولا تحتاج خادمًا أو اشتراكًا.
- ترحيل البيانات القديمة من النسخة السابقة عند أول تشغيل.
- ربط كل عملية شراء بصنف محدد وتحديث الرصيد وقيمة المخزون تلقائيًا.
- إضافة التكلفة الواصلة للواردات: سعر الشراء والشحن والجمارك والتكاليف الأخرى.
- ربط كل عملية بيع بصنف محدد ومنع البيع عند عدم كفاية الرصيد.
- حساب متوسط تكلفة المخزون وتكلفة البضاعة المباعة والربح الإجمالي.
- تسجيل التحصيلات وحالة المصروف: مدفوع أو مستحق.
- فصل سجل الرواتب حسب الشهر لمنع تكرار الراتب في التقارير.
- تقارير شهرية موحدة للإيرادات وCOGS والمصروفات والرواتب وصافي الربح.
- تنبيهات حد إعادة الطلب وقيمة المخزون.
- تصدير واستيراد نسخة احتياطية بصيغة JSON.
- حماية النصوص المدخلة من إدراج HTML ضار داخل الواجهة.

## التشغيل

افتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

يفضل استخدام خادم محلي لأن بعض المتصفحات تقيد IndexedDB عند فتح الملفات مباشرة عبر `file://`.

## قاعدة البيانات المجانية

يستخدم التطبيق IndexedDB داخل المتصفح. هذا مناسب لمصنع متوسط يعمل من جهاز أو متصفح واحد، مع ضرورة استخدام زر **تصدير نسخة احتياطية** بانتظام.

هذه النسخة لا توفر مزامنة بين عدة أجهزة أو مستخدمين. إذا احتاج المصنع ذلك مستقبلًا، يمكن نقل نفس نموذج البيانات إلى Supabase أو Firebase مع طبقة مصادقة وصلاحيات، دون تغيير كبير في تصميم الواجهة.

## سياسة الحساب الحالية

يستخدم التطبيق متوسط التكلفة المتحرك للمخزون. عند الاستلام تضاف التكلفة الواصلة إلى قيمة المخزون، وعند البيع تحسب تكلفة البضاعة المباعة وفق متوسط التكلفة وقت الحركة. الربح التشغيلي الشهري هو:

```text
الإيرادات - تكلفة البضاعة المباعة - المصروفات - الرواتب
```

هذه لوحة إدارة تشغيلية وليست بديلًا عن برنامج محاسبي قانوني أو مراجعة محاسب معتمد.
