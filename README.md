# مصنع الجرافيت - لوحة إدارة داخلية

مشروع واجهة أمامية فقط باستخدام HTML وCSS وJavaScript.

## الميزات
- لوحة تحكم رئيسية
- إدارة المخزون
- الواردات والصادرات
- المصاريف
- العمال والرواتب
- العملاء والموردون
- التقارير
- حفظ محلي داخل المتصفح
- تصدير واستيراد JSON

## التشغيل
افتح `index.html` مباشرة في المتصفح.
